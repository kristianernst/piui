# Chat UI Reference

This folder is non-shipping visual reference material for piui. The runtime app does not import these files.

Use it for layout, spacing, motion, and component behavior cues only. Do not copy the Aria product name, mock business copy, mocked data flows, CDN HTML bootstrapping, or browser-only demo logic into the Pi implementation.

The Pi app source of truth remains `src/` plus the architecture in `design.md`.
